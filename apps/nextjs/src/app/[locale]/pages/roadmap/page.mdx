# roadmap

here's what I'm up to with the app in the foreseeable future. for the time being, I'm working on this in my free time. so be patient.

## planned features

- accessibility improvements!! this is a big one. I'm not a pro at this, so I'm
  learning as I go. if you have any suggestions, [please let me know!](mailto:strathausen@gmail.com)
- coordinates (lat/long) for group locations, so you can filter groups by geographical distance
- actually private groups. you can already pick "private" in the group settings,
  but right now that's only a label - membership and content are not hidden yet.
  this is next on the list.
- waitlist for meetups
- reaction to posts
- notifications

## in progress

- nothing at the moment. I'm picking the next thing from the list above.

## completed

- uploading a group image
- profile pages
- profile images
- pledge boards for meetups (who brings what? who can help with what?)
- print view for groups, with qr code for easy sharing
- max capacity for meetups
- "full" status for meetups (derived from the max capacity)
- short links for groups
- time zone for groups
- free-text location for groups
- spanish locale 🇪🇸

## ideas for the future

I haven't fully thought these through yet, but here are some ideas I definitely want to explore:

- a **mobile app**
- a **chat** feature
- activity feed
- follow / befriend people and see their groups / meetups
- discussions in meetups
- uploading images / image gallery
- monetization for the platform. the features as they are now will always remain
  free! it might be either a _really cheap_ one-time fee (maybe 50$?) or a *really cheap*, optional
subscription model (like 10$/yr) to support the development and pay for hosting.
  no ads, no selling of data, ever. [open for suggestions!](mailto:strathausen@gmail.com)
- a way to find people with similar interests
- polls in meetups
- calendar view for meetups
- time slot finding for meetups, like doodle or noodle

## non-goals

- charging fees for meetups. you can use [lu.ma](https://lu.ma) for that which is really great btw, cheap and pretty.
